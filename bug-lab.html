Litter Bug / bug lab

Proof of concept. Hash a seed string, draw a procedural insect from it.
All anatomy is catalog-driven. Bodies, wings, heads, and patterns are PNG sprites in assets/ tinted per bug. Legs and antennae are inline SVG drawn from legs.json / antennae.json shape params. Same seed string always produces the same bug. Open view-source: to see _generateBugSVG.
