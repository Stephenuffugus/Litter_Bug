# LITTER BUG / PART_CATALOG.md
# The per-piece art structure. For EVERY piece and EVERY style of that piece:
#   (1) the EXACT formula that generates it deterministically from the hash, and
#   (2) an authoring PROMPT to produce that piece as art in the one locked style.
# Procedural (formula) ships today; authored art (prompt) drops onto the SAME
# socket later, per piece, without touching determinism or game logic.
# Source of truth = bug-engine.js `_generateBugSVG`. Last updated 2026-07-18.

--------------------------------------------------------------------------------
## 0. THE SHARED CONTRACTS (read first — every piece obeys these)
--------------------------------------------------------------------------------

### 0.1 The roll source (determinism)
One PRNG drives every choice, seeded from the codeblock:

    R = seededRng(hash + '|grow')      // cyrb128 -> sfc32, pure int ops, browser==node
    t = hashToBugTraits(hash)          // gives t.palette (0..79)

`R()` returns a float in [0,1). Every piece below names its draw. **Draw ORDER
is fixed and load-bearing** — a piece is generated by consuming R() at its slot
in the sequence (see 0.6). Add new pieces at the END of the order only, or every
existing bug changes.

### 0.2 The canvas + pose
- viewBox `0 0 200 200`. Bug faces **RIGHT**. Body baseline `cy = 110`, centered `cx = 100`.
- After assembly the whole bug is fit into a `176 x 182` box (uniform scale `f`), so pieces may be authored a bit generous; the fit pass reels them in.
- Z-ORDER (back to front): `shadow -> back(wings,tail,spines) -> legs -> body -> plates -> stitches -> shell(elytra) -> front(antennae,horns,jaws,eyes)`.

### 0.3 Growth (level -> how much has grown in)
    growth = clamp(level / 22, 0.12, 1)
Each piece has a **threshold** in [0.12 .. 1]; it renders only when `growth >= threshold`.
So the same hash draws the same body plan at every level; level just gates visibility.
(Upgrade path: a piece may ship 2-3 nested LOD tiers picked by (threshold, level).)

### 0.4 Recolor roles (palette = PALETTES[t.palette])
Author art in **GRAYSCALE** (value only). The engine tints per role at runtime:
- `primary` = body base   - `secondary` = head + elytra   - `accent` = wing membrane
- `dark` = shadow/deep   - `ol = dark darkened 20%` = the ink OUTLINE color
- `spineCol = mix(primary,dark,.30)` = horns/tails/spines/jaws hard parts
- `stitchCol = light(dark,.35)` = the cross-stitch seams
- Patchwork: each body segment gets its own material tint (see BODY).
Deliver value-only masters + (optional) an ID mask; never bake final color.

### 0.5 The one locked STYLE (prefix EVERY authoring prompt with this)
> flat vector mascot creature part, clean, friendly, single subject, facing right,
> **bold uniform dark outline**, two flat shaded tone bands plus one small soft
> highlight, matte, minimal gradient, crisp readable silhouette, centered,
> **grayscale value study (no hue)**, even soft light from upper-left, transparent
> background, connection stub bled to the LEFT/anchor edge
> `--style raw --no color hue text background shadow --ar 1:1`  `--sref <GAME_SREF once minted>`

Recraft equivalent (true vector, better for recolor): select the saved **"Litterbug Flat"**
style, `substyle: 2D flat vector, grayscale, bold outline`, transparent bg, 1:1.

Mint the GAME_SREF once (one hero bug you love), record it in ART_STYLE.md, then
every prompt below carries it so all 20+ pieces share one look.

### 0.6 Fixed draw order (the generation sequence, for reference)
`N -> rTail -> rHead -> seg jitter[xN-2] -> plan.legs[xN] -> plan.wings -> plan.horns
-> plan.pincers -> plan.tail -> plan.spines[xN] -> plan.extraEyes -> wSweep,hornCurl,tailLen
-> wingKind -> jawKind,tailKind -> nMat + mats fill -> segMat[xN-1] -> antKind,eyeKind
-> legKind -> plateKind`.

================================================================================
## 1. BODY (the spine)  — z: body ; anchor: the whole rig ; threshold: always
================================================================================
The chassis every other piece anchors to. One silhouette family today (segmented
spine); style = the segment profile.

**FORMULA**
    N      = 3 + floor(R()*4)                 // 3..6 segments
    rTail  = 13 + R()*7                        // rear radius 13..20
    rHead  = 8  + R()*4                         // head radius 8..12
    seg[i].r = lerp(rTail, rHead, i/(N-1))
             + (i in 1..N-2 ? (R()-0.5)*4 : 0) // mid-segment jitter
    // lay left->right along a shallow dorsal arch:
    seg[i].x = chain, gap = (r_i + r_{i+1})*0.6
    seg[i].y = cy + sin(i/(N-1)*PI)*-4 - (i==last ? 4 : 0)
    thoraxI  = N-2 (wing anchor) ;  head = seg[N-1]
    draw: filled circle per segment (head uses `secondary`, others their material)

**STYLE VARIANTS (segment profile)** — pick by a new `bodyKind` roll if authored:
- `grub`   : radii taper smoothly, low jitter — a soft caterpillar.
- `armored`: uniform radii, tighter overlap — reads as a hard beetle/pillbug.
- `wasp`   : strong taper + a pinch between thorax/abdomen.

**PROMPT (grayscale master, canvas 200x100, pivot bled to LEFT edge)**
- grub:    `[STYLE] a plump segmented caterpillar body, 4-5 soft round segments in a gentle left-to-right arch, no head features, no legs, matte, side view`
- armored: `[STYLE] a hard-shelled beetle abdomen+thorax, tightly overlapping armored segments, subtle plate ridges, side view, no head, no legs`
- wasp:    `[STYLE] a tapered insect body with a narrow waist between thorax and abdomen, sleek, side view, no head, no legs`

================================================================================
## 2. WINGS  — z: back (elytra: shell) ; anchor: seg[thoraxI], wy = y - r*0.3
   threshold: 0.42 + R()*0.25 (~0.42..0.67) ; present 75% ; wingKind = floor(R()*3)
================================================================================
The most visible silhouette driver. wSweep = (R()-0.5)*16 skews the wing tip.

**FORMULA — style 0 MEMBRANE pair** (`membrane(ox,oy,sc,op)`, sc=1)
    path: M(ox,oy) Q(ox-32,oy-38) (ox+8+wSweep, oy-44) Q(ox+36,oy-32)(ox+32,oy-6)
          Q(ox+18,oy+2)(ox,oy) Z          // one rounded blade, fill `accent` gradient
    + a single vein: M(ox+2,oy-3) Q(ox+8,oy-26)(ox+20,oy-30)
**FORMULA — style 1 DRAGONFLY** (fore + hind): draw `membrane(wx-3, wy+4, 0.72, .8)`
    (small hindwing, behind) then `membrane(wx, wy, 1.18, .95)` (long forewing). sc=1.18.
**FORMULA — style 2 ELYTRA shell** (hard beetle back, drawn in the `shell` layer ON TOP):
    a = seg[0], b = seg[thoraxI], lx = a.x-a.r*0.2, rx = b.x+b.r,
    topY = min(a.y,b.y) - max(a.r,b.r) - 6
    dome path lx->topY->rx, seam line + one gloss ellipse. fill `secondary` gradient.
    (suppresses carapace; wingUp reserve = elytra 26 / dragonfly 56 / membrane 46)

**PROMPTS (canvas 256x128, pivot bled to lower-LEFT root)**
- membrane:  `[STYLE] a single rounded insect forewing, one membrane blade with 2-3 faint veins, translucent look via value only, root at lower-left, tip up-right`
- dragonfly: `[STYLE] a long narrow dragonfly wing pair, one longer forewing over a shorter hindwing, fine vein lattice, elegant, roots at lower-left`
- elytra:    `[STYLE] a smooth hard beetle wing-case (elytra) shell, one glossy domed half-shell with a center seam and a soft top gloss, covers the back, root at lower-left`

================================================================================
## 3. JAWS / MOUTH  — z: front ; anchor: head jx = head.x + head.r*0.8, jy = head.y
   threshold: plan.pincers 0.3 + R()*0.3 ; present 60% ; jawKind = 1 + floor(R()*3)
================================================================================
**FORMULA — 1 PINCERS** (curved, `spineCol`/`ol` strokes):
    two arcs: q(9,3,7,10) at jy+r*0.3 and q(8,5,4,11) at jy+r*0.55
**FORMULA — 2 TUSKS** (crossing, forward): two arcs q(12,0,15,8) at jy+r*0.2 and
    q(12,2,15,-3) at jy+r*0.55, stroke-width 2.6
**FORMULA — 3 MANDIBLES** (open, filled triangles): l(12,-3)l(-2,7)z at jy+r*0.12 and
    l(12,4)l(-3,-7)z at jy+r*0.62, fill `spineCol`

**PROMPTS (canvas 64x64, pivot bled to LEFT = where it meets the head)**
- pincers:   `[STYLE] a pair of slim curved insect pincers, hooked tips, hard chitin, opening rightward from a left mounting stub`
- tusks:     `[STYLE] two short forward-crossing insect tusks/mandibles, blunt, sturdy, from a left mounting stub`
- mandibles: `[STYLE] a pair of open triangular beetle mandibles, wide gaping bite, serrated inner edge, from a left mounting stub`

================================================================================
## 4. TAIL / REAR  — z: back ; anchor: seg[0] (tx,ty) ; tailLen = 10 + R()*8
   threshold: plan.tail 0.6 + R()*0.3 ; present 50% ; tailKind = floor(R()*3)
================================================================================
**FORMULA — 0 STINGER**: path M(tx,ty) q(-tailLen,4)(-tailLen*1.2,-8) l(5,-4) z, `spineCol`
**FORMULA — 1 FORKED**: two prongs M(tx,ty) l(-tailLen,-6)l(3,5)z and l(-tailLen,8)l(3,-5)z
**FORMULA — 2 CLUBBED**: stalk q(-tailLen,2)(-tailLen*1.1,0) + circle r=(4+tailLen*0.12) at the end

**PROMPTS (canvas 96x64, pivot bled to RIGHT = where it meets the rear segment)**
- stinger: `[STYLE] a single tapered insect stinger curving up-and-back, sharp tip, from a right mounting stub`
- forked:  `[STYLE] a two-pronged insect tail fork (cerci), symmetric prongs, from a right mounting stub`
- clubbed: `[STYLE] an insect tail with a rounded bulb club on a short stalk, heavy tip, from a right mounting stub`

================================================================================
## 5. ANTENNAE  — z: front ; anchor: head ax = head.x + r*0.2, ay = head.y - r*0.8
   threshold: 0.12 (grows in first) ; ALWAYS present ; antKind = floor(R()*3)
================================================================================
Two curved strokes to tips t1 = (ax+20, ay-20), t2 = (ax+12, ay-24).
**FORMULA — 0 PLAIN**: the two Q-curves only.
**FORMULA — 1 CLUBBED**: + a filled circle r=2.5 at each tip.
**FORMULA — 2 FEATHERED**: + 3 short barbs `l 4 -1` along each stalk at t=1/4,2/4,3/4.

**PROMPTS (canvas 64x64, pivot bled to lower-LEFT = the head mount)**
- plain:     `[STYLE] a pair of thin curved insect antennae sweeping up and back, tapering, from a lower-left head mount`
- clubbed:   `[STYLE] a pair of insect antennae with small round club tips, thin stalks, from a lower-left head mount`
- feathered: `[STYLE] a pair of feathered/plumose moth antennae, fine comb barbs along each stalk, from a lower-left head mount`

================================================================================
## 6. EYES  — z: front ; anchor: head (eyeX = head.x + r*0.3, eyeY = head.y - r*0.2)
   ALWAYS present ; eyeKind = floor(R()*3) ; eR = head.r*0.42
================================================================================
**FORMULA — 0 SINGLE**: ellipse rx=eR*0.85 ry=eR (dark) + a small white catchlight circle.
**FORMULA — 1 COMPOUND**: 5 facet circles (r=eR*0.95*0.44) at offsets {0,0},{-.55,-.5},{.5,-.45},{-.45,.55},{.55,.45} + one catchlight.
**FORMULA — 2 LIDDED**: the single eye + a brow arc `q(eR*0.85,-eR*0.6, eR*1.7, 0)` over it.
(plan.extraEyes 40%: a small second eye ellipse when threshold 0.7 + R()*0.25 met.)

**PROMPTS (canvas 48x48, centered pivot — sits on the head)**
- single:   `[STYLE] one large round glossy insect eye with a single bright catchlight, dark iris, cute`
- compound: `[STYLE] a clustered compound insect eye, small hex facets, one catchlight, dark`
- lidded:   `[STYLE] a half-lidded insect eye with a heavy brow, sleepy/menacing, one catchlight`

================================================================================
## 7. LEGS  — z: legs ; anchor: per body segment underside (mid seg 1..thoraxI)
   threshold: per seg 0.12 + R()*0.5 (rear seg 0.4 + R()*0.4) ; legKind = floor(R()*3)
================================================================================
Two 3-point jointed strands per qualifying segment, to ky = s.y + r*0.7 + 8.
**FORMULA — 0 THIN**: stroke-width 2.2 / 2.6.
**FORMULA — 1 STURDY**: stroke-width +1 (3.2 / 3.6).
**FORMULA — 2 RAPTORIAL**: thin legs + ONE bent hooked foreleg on the thorax:
    M(rx0,ry0) L(+7,+10) L(+17,+3) L(+15,+11), width 3.4, from thorax.
Legs stay PROCEDURAL FOREVER (thin parts are worst-case for every art tool).

**PROMPTS (only if ever authored; canvas 64x96, pivot bled to TOP = body mount)**
- thin:      `[STYLE] a single thin jointed insect leg, two joints, hair-fine, from a top body mount`
- sturdy:    `[STYLE] a thicker jointed insect leg, sturdy segments, from a top body mount`
- raptorial: `[STYLE] a raptorial mantis foreleg, bent and hooked, grasping spines, from a top body mount`

================================================================================
## 8. CARAPACE (dorsal plates)  — z: plates (over body, under seams)
   present ~40% AND not elytra ; plateKind = (R() < 0.4) ; one plate per body seg
================================================================================
**FORMULA**: per non-head segment, a domed cap over the top:
    M(s.x-pw, s.y-r*0.12) Q(s.x, s.y-r*1.24)(s.x+pw, s.y-r*0.12)
    Q(s.x, s.y+r*0.14)(s.x-pw, s.y-r*0.12) Z   where pw = r*0.86
    fill = mix(segMaterial, dark, .32) ; + a light crest arc on top.
**PROMPT (canvas 96x64, pivot bled to BOTTOM = body top)**
`[STYLE] a single curved beetle back-plate / dorsal armor segment, domed, subtle ridge crest, hard chitin, mounts on the body top`

================================================================================
## 9. HORNS  — z: front ; anchor: head top ; threshold 0.55 + R()*0.35 ; present 55%
================================================================================
**FORMULA**: one curved horn, hornCurl = (R()-0.5)*0.6 sets the sweep:
    M(head.x+r*0.1, head.y-r*0.85) Q(head.x+r*0.6+hornCurl*10, head.y-r*1.6)
      (head.x+r*1.1, head.y-r*1.5)  stroke `spineCol` width 3
**PROMPT (canvas 64x80, pivot bled to BOTTOM = head top)**
`[STYLE] a single curved rhino-beetle horn sweeping up and forward, hard chitin, from a bottom head mount` (variants later: straight spike / branched / paired)

================================================================================
## 10. DORSAL SPINES  — z: back ; per seg threshold 0.35 + R()*0.5 ; present 50%/seg
================================================================================
**FORMULA**: per qualifying segment, a small triangle spike above it:
    M(s.x, s.y-r) l(-3,-9) l(6,0) z   fill `spineCol`
**PROMPT (canvas 32x48, pivot bled to BOTTOM)**
`[STYLE] a single small triangular back spike / spur, hard, from a bottom mount` (variants: curved quill / hair tuft)

================================================================================
## 11. MATERIALS / PATCHWORK (recolor, not a shape)
================================================================================
**FORMULA**: matPool = [secondary, mix(primary,dark,.28), mix(primary,accent,.35),
    light(primary,.18), dark(primary,.18)]. nMat = 2 + floor(R()*3). mats[0]=primary,
    then nMat-1 picks from matPool. Each body segment's material = mats[floor(R()*mats.length)]
    (head is always `secondary`). This is the "sewn from litter" per-segment tint.
No prompt — this is the recolor engine. Authored parts inherit it via role tokens.

--------------------------------------------------------------------------------
## HOW TO USE THIS
--------------------------------------------------------------------------------
1. Mint the ONE `--sref` from a hero bug; paste into ART_STYLE.md and 0.5.
2. Author any piece with its prompt(s), grayscale, on its canvas, connection bled
   to the named pivot edge. Background-remove -> straight alpha -> vectorize (vtracer/
   potrace) -> SVGO -> `<symbol id="sym-<part>-<style>">`.
3. Register it in `scripts/art-layers.js` with `source: 'vector'` for that (part,style);
   the renderer's per-part dispatch draws `<use>` instead of the procedural fn. Growth,
   anchor, z, and recolor are unchanged (they live in code), so it just works and is
   reversible per piece.
4. Legs, antennae, spines: keep procedural. Wings -> bodies -> heads are the upgrade order.
